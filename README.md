## 当前实现

- Material 3 去重、校验与 YCK 页面，保留 2.3.10 的签名、图标与 YCK 收集兼容；YCK 支持手动无缓存刷新。
- 导入阅读扫描已装分支：0 个提示、1 个直达、多个选择器后指定包名走 `legado://import/bookSource`；大批量 JSON 仅通过本机一次性短时地址交给阅读读取。
- `bookSourceUrl` 支持 `#简体`、`#大改`、`#🎃` 等身份标签：标准/严格去重保留标签，校验 HTTP 时只请求井号前地址。
- 解析下载并发 **1–10**（主页「并发请求」）。同域一次只下一份，避免 YCK 三连发互相挤死。
- 解析只走直连，不再回退本机死代理。超时/重置/429/5xx 最多再试 2 次（间隔 0.4s / 1.2s），进度行会标「慢网重试中」。
- 校验默认超时 180 秒；并发可在 **1–500** 间调整，默认 8；探测轮数默认/上限 **10**。
- 校验按线程池并发跑；网站失效/超时或已过半即停，不再打满 10 轮。收尾只按已测中位耗时比同域，不再重打 HTTP。
- 校验过程与结果展示「检验耗时」；超过 1 分钟会提示过慢原因。
- 校验对话框可填搜索关键词（默认「我的」）；超时、并发、探测轮数、搜索词和勾选会记住，可用「重置默认」恢复。
- 按 `bookSourceType` 和名称/分组判断小说、漫画、视频、音频、文件；内容探测和结果统计按类型分类。
- 检验对话框可勾选要检验的类型；结果区用开关决定导入/保存带哪些类型（例如只开小说）。
- 校验完成后按同类型同域名只留最快可用（www 相同）；耗时接近则都保留。小说/漫画/音频/视频/文件互不合并。
- 去重解析和源校验与当前 Tab 解耦；切换到 YCK 不取消任务，YCK 页显示后台任务进度入口。
- 停止校验会取消 HTTP 连接；高并发取消要求及时完成且无死锁。取消后同域最快确认不删源。
- 当前校验为 Phase-2：真实 HTTP 请求、规则存在性和返回体物证探测；尚未集成完整 Rhino/WebBook CSS/XPath/JS 规则求值。
