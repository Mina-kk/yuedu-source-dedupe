# 3.0.0-md3 发布说明

## 重构

- 项目迁移为标准 Android Gradle 工程。
- 界面更新为 Material 3。
- 去重、书源校验和 YCK 页面整合到同一应用。
- 去重和校验任务支持切换页面后继续运行。

## 修复与新增

### 去重

- 修复 URL 尾斜杠、默认端口、查询参数和常见跟踪参数的处理。
- 支持 `#简体`、`#大改`、`#🎃` 等书源身份标签。
- 标准和严格模式保留身份标签，激进模式按站点合并。
- 网络请求只使用身份标签前的实际地址。
- 切换模式或名称清理选项后重新计算结果。

### 导入和 YCK

- 支持本地文件和网络地址导入。
- 兼容数组、`data`、`list`、`sources` 包装及单个书源对象。
- 网络请求支持重定向、gzip 响应和下载大小限制。
- 网络地址直接请求，不使用额外代理。
- YCK 新增站点入口切换和无缓存刷新。
- 支持将 YCK 页面中的书源地址添加到去重工具。

### 书源校验

- 新增搜索、发现、详情、目录和正文阶段校验。
- 支持超时、停止、失败原因分类和仅导出可用源。
- 校验并发范围为 **1–100**，默认 8。

### 导入阅读

- 改为打开阅读的书源批量选择界面。
- 由用户选择并确认需要导入的书源。
- 不直接写入阅读书源数据库。
- 使用一次性本机地址传递批量 JSON。
