# 书源可用性校验

3.0.7-md3 校验支持 `book` / 上下文变量（`book.name`、`book.author`、`book.bookUrl`、`book.tocUrl`、`book.origin`、`baseUrl`、`source.*`）与常见模板表达式（带空格的 `key`/`page`、纯算术、`java.encodeURI`），按链路实时填入；仍无法求值的模板记「未覆盖」，不计失败；`tocUrl` 为提取规则时不再拼成地址。

3.0.6-md3 将校验对话框功能开关统一为与主页一致的 Material 3 Switch 功能卡，新增「快速准确」一键预设，并把同域速度淘汰收紧为仅完整身份等价副本可删；校验证据不再按裸 URL 共享。

## 配置

### 超时

- 默认值：180 秒。
- 设置范围：0–300 秒。
- 界面选择 0 时使用默认值。
- 内部值低于 1 秒时归一化为默认值，高于 300 秒时归一化为 300 秒。

### 并发

- 默认值：8。
- 设置范围：**1–500**。
- 小于 1 时归一化为 1。
- 大于 500 时归一化为 500。
- 界面、配置归一化和校验线程池使用同一上限。
- 主页「并发请求」是解析下载并发，范围 **1–10**，不是校验并发。

### 探测轮数

- 默认值：10。
- 设置范围：1–10，上限 10。
- 每源在同一工作线程内连续探测。
- 成功过半才算可用。
- 网站失效或超时不再打满剩余轮次。
- 耗时取成功轮中位数。

### 搜索关键词

- 默认值：「我的」。
- 用于替换搜索地址中的 `{{key}}` 和 `{key}`。
- 空白输入回退为默认值。
- 与超时、并发、探测轮数和校验勾选一起保存。

### 功能开关

校验对话框下半部分是统一的功能开关卡，四个开关均为 Material 3 Switch（与主页底部开关同风格），自上而下依次为：

1. 清理需要登录的源
2. 删除弹窗验证码的源
3. 快速模式
4. 快速准确（推荐）

说明行只跟随「快速准确」，与它在同一卡片层级内，不影响其它开关的位置。

- 「清理需要登录的源」默认开启：`loginUrl` 非空或存在实际 `loginUi` 登录表单时，不导入、不保存。
- 「删除弹窗验证码的源」默认勾选：检出后从导入/保存结果里排除。
- 「快速模式」只跑搜索 + 详情，探测轮数与超时仍按滑杆手动值。
- 「快速准确（推荐）」是一键预设：勾选后立即套用搜索 + 详情、探测 3 轮、超时 60 秒并锁定滑杆；取消勾选即退出预设并恢复手动步骤选择。

校验步骤（搜索/发现/详情/目录/正文）与类型多选（小说/漫画/视频/音频/文件）仍为复选框，未换成 Switch。

### 快速准确预设

- 默认只测搜索 + 详情，探测 3 轮、超时 60 秒。
- 勾选时强制套用预设参数，滑杆锁定，防止残留值覆盖 3 轮 / 60 秒。
- 关闭同域速度淘汰：所有源仅按速度排序参考，绝不因同域耗时被淘汰。
- 默认保留未通过 / 待复核源：快速准确下 `仅导出可用源` 自动关闭，待复核源进入结果不被误删；手动打开该开关才会排除。
- 预设勾选即开启快速模式，退出预设同时退出快速模式。

### 重置默认

「重置默认」会恢复超时 180 秒、并发 8、探测 10、关键词「我的」，以及全部校验阶段、类型勾选和「删除弹窗验证码的源」。

检验对话框阶段勾选、校验类型各排一行。

导出时保留原分组，并追加 `✔年月日分类（数量）`，例如 `✔2026-8-23小说（120）`。

## 校验阶段

可选择：

1. 搜索
2. 发现
3. 详情
4. 目录
5. 正文

搜索和发现至少启用一项。关闭详情时会同时关闭目录和正文；关闭目录时会同时关闭正文。

## 书源类型

按 `bookSourceType` 判断：

- 0 或缺省：小说
- 1：音频
- 2：漫画
- 3：文件
- 4 或名称/分组提示：视频

检验对话框可选择要校验的类型。未选择的类型会跳过。

内容探测按类型进行：

- 小说：文本
- 漫画：图片地址
- 视频：播放地址
- 音频：音频地址
- 文件：下载痕迹

内容失败文案按类型：正文 / 图片 / 播放 / 音频 / 下载失效。

## HTTP 判定

- 仅 200–399 且有响应体、非验证码/Cloudflare 挑战才算网站连通。
- 4xx / 5xx / 空体记「网站失效」。
- 验证码页单独记「弹窗验证码」。
- `#简体` / `#🎃` 等身份标签校验时剥掉，导出 JSON 保留。
- 非 `http/https` 源跳过探测，不进最快竞争。

## 解析下载

- 网络地址直接请求，不使用额外代理。
- 使用常见移动浏览器 User-Agent，并带上同源 Referer。
- 请求 gzip。
- 同域最多 2 路并行；不同站点仍可并发。
- 连接超时 5 秒；读超时 45 秒。
- DNS 失败不重试。超时、连接重置、空体、429 / 408 / 502 / 503 / 504 最多再试 2 次（间隔 0.4s / 1.2s）。
- 404 / 403 / 400 不重试。
- 进度行会显示「慢网重试中」。
- 输入框识别同行、中文逗号和全角空格分隔的多个地址。
- 解析前去掉 BOM、`)]}'` 和常见 HTML 包裹。
- 下载后用字符串计数，不再为进度先完整解析一遍 JSON。

## 同域最快

- 按小说 / 漫画 / 音频 / 视频 / 文件分桶。
- 桶内主机名小写、去掉 `www.`，忽略路径、query 和 `#` 身份标签。
- 可用优先，再比中位耗时；速度只是排序参考，本身不构成删除依据。
- 真正淘汰需同时满足三点：
  1. 手动模式显式开启速度淘汰（「快速准确」预设恒为不淘汰）；
  2. 候选与最快源是完整身份等价副本——URL + 名称 + 整个 raw 规则深等，即前序去重本就认定的同一源；
  3. 耗时差超出「接近」范围且确认探测稳定更快。
- 规则、路径或字段任一不同的同域源一律保留，仅计入参考计数，不建重复组，不推高重复删除计数。
- 校验收尾只按已测中位耗时比较，不再额外 HTTP。
- 停止校验后不做确认探测，不按未确认耗时淘汰。

## 校验证据

- 一条校验结果只归属于可证明为同一源的记录：优先按 `SourceRecord` 实例匹配，去重/合并换实例后才用「URL + 名称 + 完整 raw」深等的唯一指纹兜底。
- 绝不按裸 URL 匹配：同 URL 但规则/字段不同的源互不套用校验结果；指纹多义（同键多条）直接剔除不猜。
- 无证据的源进入「待复核」保留，不被别人的「可用」带上光环。

## 停止校验

停止操作会取消正在运行的任务和活动 HTTP 连接。已经完成的结果会保留并汇总。取消后同域候选全部保留。

## 导入阅读

- 扫描已装且能响应 `legado://import/bookSource` 的阅读。
- 0 个提示安装；1 个直达；多个弹出选择器，上次选择置顶。
- 仍通过一次性本机 JSON 地址导入，不写阅读数据库。
- 导入和保存只处理结果区已打开的类型。
- 仍可启用「仅导出可用源」。

## 结果分类

结果可能包含：

- 校验超时
- 搜索链接规则为空
- 搜索失效
- 发现失效
- 弹窗验证码
- 详情失效
- 目录失效
- 正文失效
- 图片失效
- 播放失效
- 音频失效
- 下载失效
- 网站失效
- js失效
- 未覆盖（标记「待复核」）

「未覆盖 / 待复核」：源启用的校验步骤有规则，但对应链路 URL 缺失（例如目录规则存在但目录地址为空），或 URL 模板里有本工具无法求值的 `{{...}}` 表达式，无法完成该步探测。此类源不计失败、不参与同域淘汰，保留在结果里待人工复核；仅在用户显式勾选「仅导出可用源」时才被过滤。

界面会显示检验耗时。超过 1 分钟时提示过慢原因。

## 当前限制

当前实现尚未包含与阅读 WebBook 完全一致的 Rhino JavaScript、CSS 和 XPath 规则执行。复杂动态脚本、登录状态、验证码和访问限制可能影响校验结果。

## 测试

JVM 测试已验证：

- 默认并发为 8。
- 0 归一化为 1。
- 500 保持为 500。
- 501 归一化为 500。
- 最大并发常量为 500。
- 探测轮数默认 10，成功过半才可用。
- 空白关键词回退为「我的」。
- 书源类型判断和内容探测。
- 取消后不按未确认耗时淘汰同域源。
- 同域解析排队、瞬时失败重试、404 不重试。
- 快速准确预设不淘汰仅排序、保留待复核源。
- 同 URL 不同规则的源不共享校验证据。
- 非完整身份等价的同域源即便更慢也不被误删、不产生幻影重复组。
- 未覆盖源归入待复核聚合，不计失败。
- book 变量与算术/编码模板解析。
- 未解析模板记未覆盖，不计失败。
