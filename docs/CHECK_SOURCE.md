# 校验源是否可用

- 默认超时 180 秒（滑条 0–300；选择 0 时按默认 180 秒执行）
- 并发默认 8，可在 **1–500** 间调整；`CheckSourceSettings.MAX_CONCURRENCY` 是配置归一化和线程池的统一上限（0→1、500 保持、501→500）
- 探测轮数默认 **10**，范围 **1–10**，上限 10；每源在同一 worker 内串行探测，成功过半或网站失效/超时即停，耗时取成功轮中位数
- 主页「并发请求」是解析下载并发，范围 **1–10**，不是校验并发
- 解析下载：直连、浏览器 UA；同域串行；瞬时失败最多 3 次（含首次），不重试 4xx（429/408 除外）
- 勾选：搜索 / 发现 / 详情 / 目录 / 正文
- 搜索关键词：对话框「搜索书名、作者」，默认「我的」；空白回退；与超时、并发、探测轮数、勾选一起写入 `SharedPreferences("check")`
- 「重置默认」恢复超时 180、并发 8、探测 10、关键词「我的」、全部阶段和类型勾选
- 类型：按 `bookSourceType` 判断小说/漫画/视频/音频/文件；0/缺省时用名称、分组补判
- 可勾选要校验的类型；未勾选跳过
- 内容探测按类型：小说看文本，漫画看图片，视频看播放地址，音频看音频地址，文件看下载痕迹
- 目录依赖详情，正文依赖目录
- 至少开启搜索或发现之一
- 结果分组：校验超时、搜索链接规则为空、搜索失效、发现失效、详情/目录/正文或图片/播放/音频/下载失效、网站失效、js失效
- HTTP 判定：仅 200–399 且有响应体、非 Cloudflare 挑战才算网站连通；4xx/5xx/空体记「网站失效」
- `#简体` / `#🎃` 等身份标签校验时剥掉，导出 JSON 保留
- 非 `http/https` 源跳过探测，不进最快竞争
- 结果按类型计数：小说 a/b · 漫画 c/d · 视频 e/f
- 校验完成后默认仅导出可用源，并按 **同类型同域名** 只留最快可用（www 视为相同）；耗时接近则都保留
- 结果区：去重四格（原始/重复/有效/错误）、校验三格（可用/失败/超时），类型行带可用率进度条和开关
- 关掉某类再导入/保存就不会带上它；底部显示将导入条数；开关会记住
- 检验对话框里的类型勾选仍然表示「要不要检验这类源」，和结果区开关分开

## 运行与取消

- 校验和去重解析不依赖当前 Tab 的可见性；切换到 YCK 不会重置运行标志、置空任务对象或调用 `cancel()`。
- YCK 页会显示后台解析/校验进度 Chip，点击可返回去重页查看完整进度和停止入口。
- 停止校验会断开活动 HTTP 连接；排队任务启动后看到 `cancelled` 并递减 latch，避免死锁。
- 取消后不做层 2 确认探测：同域候选全部保留，不按未完成轮次的耗时淘汰。
- 校验收尾只按已测中位耗时比同域最快，不再额外 HTTP；进度 100% 后应马上出结果。
- 500 并发时使用有界线程池；层 1 的 N 次探测在同一 worker 内串行，不把轮次再乘进池大小。
- 界面显示检验耗时；超过 1 分钟提示死站超时、多轮探测是过慢主因。

## 多阅读导入

- 扫描已装且能响应 `legado://import/bookSource` 的阅读分支。
- 0 个提示安装；1 个直达；多个弹出选择器（名称 + 包名），上次选择置顶。
- 仍走 `ReaderImportService` 回环 JSON，不写阅读数据库。鸿蒙 HAP / 桌面 Tauri 不做。

## 引擎深度（当前）

Phase-2（非完整 Rhino）：
1. 解析 searchUrl/exploreUrl（支持 {{key}}/{{page}}、相对路径、`,{method/body/headers}`）
2. 真实 HTTP 请求（含源 header、gzip、POST body）
3. 对返回体做列表/详情/正文物证探测，并尽量串联 bookUrl → tocUrl → chapterUrl
4. URL 依赖 JS 构造且无法静态化时标记 `js失效`
5. 站点连通可按 host 短缓存；搜索/发现/详情/目录/内容每源每轮都打

完整 CSS/XPath/JS 规则求值（Rhino/WebBook）仍可继续加深。

附件 HTML「书源网址检测工具」不是检验标准：不以网页能打开判定可用，不剥 `#` 身份标签，不把同域淘汰项改标成不可用。
