# 书源可用性校验

3.0.2-md3 在阅读 CheckSource 分组上增加多轮探测、同类型同域最快可用、更高的校验并发上限，以及更稳的解析下载。

## 配置

### 超时

- 默认值：180 秒。
- 设置范围：0–300 秒。
- 界面选择 0 时使用默认值。
- 内部值低于 1 秒时归一化为默认值，高于 300 秒时归一化为 300 秒。

### 并发

- 默认值：8。
- 设置范围：**1–500**。
- 小于 1 时归一化为 1。
- 大于 500 时归一化为 500。
- 界面、配置归一化和校验线程池使用同一上限。
- 主页「并发请求」是解析下载并发，范围 **1–10**，不是校验并发。

### 探测轮数

- 默认值：10。
- 设置范围：1–10，上限 10。
- 每源在同一工作线程内连续探测。
- 成功过半才算可用。
- 网站失效或超时不再打满剩余轮次。
- 耗时取成功轮中位数。

### 搜索关键词

- 默认值：「我的」。
- 用于替换搜索地址中的 `{{key}}` 和 `{key}`。
- 空白输入回退为默认值。
- 与超时、并发、探测轮数和校验勾选一起保存。

### 重置默认

「重置默认」会恢复超时 180 秒、并发 8、探测 10、关键词「我的」，以及全部校验阶段和类型勾选。

## 校验阶段

可选择：

1. 搜索
2. 发现
3. 详情
4. 目录
5. 正文

搜索和发现至少启用一项。关闭详情时会同时关闭目录和正文；关闭目录时会同时关闭正文。

## 书源类型

按 `bookSourceType` 判断：

- 0 或缺省：小说
- 1：音频
- 2：漫画
- 3：文件
- 4 或名称/分组提示：视频

检验对话框可选择要校验的类型。未选择的类型会跳过。

内容探测按类型进行：

- 小说：文本
- 漫画：图片地址
- 视频：播放地址
- 音频：音频地址
- 文件：下载痕迹

内容失败文案按类型：正文 / 图片 / 播放 / 音频 / 下载失效。

## HTTP 判定

- 仅 200–399 且有响应体、非 Cloudflare 挑战才算网站连通。
- 4xx / 5xx / 空体记「网站失效」。
- 不以「网页能打开」为可用。
- `#简体` / `#🎃` 等身份标签校验时剥掉，导出 JSON 保留。
- 非 `http/https` 源跳过探测，不进最快竞争。

## 解析下载

- 网络地址直接请求，不使用额外代理。
- 使用常见移动浏览器 User-Agent，并带上同源 Referer。
- 同域一次只下一份；不同站点仍可并发。
- 超时、连接重置、空体、429 / 408 / 502 / 503 / 504 最多再试 2 次（间隔 0.4s / 1.2s）。
- 404 / 403 / 400 不重试。
- 进度行会显示「慢网重试中」。
- 输入框识别同行、中文逗号和全角空格分隔的多个地址。
- 解析前去掉 BOM、`)]}'` 和常见 HTML 包裹。

## 同域最快

- 按小说 / 漫画 / 音频 / 视频 / 文件分桶。
- 桶内主机名小写、去掉 `www.`，忽略路径、query 和 `#` 身份标签。
- 可用优先，再比中位耗时。
- 耗时接近或确认轮不稳定时都保留，并标记「耗时接近，未淘汰」。
- 校验收尾只按已测中位耗时比较，不再额外 HTTP。
- 停止校验后不做确认探测，不按未确认耗时淘汰。

## 停止校验

停止操作会取消正在运行的任务和活动 HTTP 连接。已经完成的结果会保留并汇总。取消后同域候选全部保留。

## 导入阅读

- 扫描已装且能响应 `legado://import/bookSource` 的阅读。
- 0 个提示安装；1 个直达；多个弹出选择器，上次选择置顶。
- 仍通过一次性本机 JSON 地址导入，不写阅读数据库。
- 导入和保存只处理结果区已打开的类型。
- 仍可启用「仅导出可用源」。

## 结果分类

结果可能包含：

- 校验超时
- 搜索链接规则为空
- 搜索失效
- 发现失效
- 详情失效
- 目录失效
- 正文失效
- 图片失效
- 播放失效
- 音频失效
- 下载失效
- 网站失效
- js失效

界面会显示检验耗时。超过 1 分钟时提示过慢原因。

## 当前限制

当前实现尚未包含与阅读 WebBook 完全一致的 Rhino JavaScript、CSS 和 XPath 规则执行。复杂动态脚本、登录状态、验证码和访问限制可能影响校验结果。

附件 HTML「书源网址检测工具」不是检验标准：不以网页能打开判定可用，不剥 `#` 身份标签，不把同域淘汰项改标成不可用。

## 测试

JVM 测试已验证：

- 默认并发为 8。
- 0 归一化为 1。
- 500 保持为 500。
- 501 归一化为 500。
- 最大并发常量为 500。
- 探测轮数默认 10，成功过半才可用。
- 空白关键词回退为「我的」。
- 书源类型判断和内容探测。
- 取消后不按未确认耗时淘汰同域源。
- 同域解析排队、瞬时失败重试、404 不重试。
