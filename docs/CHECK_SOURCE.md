# 书源可用性校验

3.0.0-md3 新增批量书源校验，用于检查明显失效、超时或规则缺失的书源。

## 配置

### 超时

- 默认值：180 秒。
- 设置范围：0–300 秒。
- 界面选择 0 时使用默认值。
- 内部值低于 1 秒时归一化为 1 秒，高于 300 秒时归一化为 300 秒。

### 并发

- 默认值：8。
- 设置范围：**1–100**。
- 小于 1 时归一化为 1。
- 大于 100 时归一化为 100。
- 界面、配置归一化和校验线程池使用同一上限。

## 校验阶段

可选择：

1. 搜索
2. 发现
3. 详情
4. 目录
5. 正文

搜索和发现至少启用一项。关闭详情时会同时关闭目录和正文；关闭目录时会同时关闭正文。

## 当前支持

- 常用 URL 模板。
- 相对地址。
- GET 和 POST 请求。
- 请求头和请求体配置。
- gzip 响应和 HTTP 重定向。
- 搜索、发现、详情、目录和正文返回内容探测。
- 书源 URL 身份标签不参与实际网络请求。

## 停止校验

停止操作会取消正在运行的任务和活动 HTTP 连接。已经完成的结果会保留并汇总。

## 结果分类

结果可能包含：

- 校验超时
- 搜索链接规则为空
- 搜索失效
- 发现失效
- 详情失效
- 目录失效
- 正文失效
- 网站失效
- js失效

启用“仅导出可用源”后，保存或导入时只处理本次校验结果为可用的书源。

## 当前限制

当前实现尚未包含与阅读 WebBook 完全一致的 Rhino JavaScript、CSS 和 XPath 规则执行。复杂动态脚本、登录状态、验证码和访问限制可能影响校验结果。

## 测试

JVM 测试已验证：

- 默认并发为 8。
- 0 归一化为 1。
- 100 保持为 100。
- 101 归一化为 100。
- 最大并发常量为 100。
