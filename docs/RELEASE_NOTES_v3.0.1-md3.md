# 3.0.1-md3 发布说明

## 书源校验

- 校验对话框可填写搜索关键词，默认「我的」。
- 超时、并发、关键词和校验勾选会记住。
- 可用「重置默认」恢复初始配置。
- 按书源类型判断小说、漫画、视频、音频和文件。
- 内容探测按类型进行。
- 结果区显示去重和校验统计。
- 可用开关选择导入或保存的类型。

## 导入阅读

- 导入和保存只处理结果区已打开的类型。
- 仍可启用「仅导出可用源」。
- 继续打开阅读的书源批量选择界面，不直接写入阅读书源数据库。
