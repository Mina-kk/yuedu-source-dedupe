# 阅读书源去重 3.0.2-md3

本版本按阅读 CheckSource 做多轮校验，并按同类型同域保留最快可用源。

## 主要更新

- 探测轮数默认 10；成功过半才可用，耗时取成功轮中位数。
- 校验并发范围 1–500，默认 8。
- 校验后按同类型同域名只留最快可用源；耗时接近则都保留。
- 停止校验不按未确认耗时淘汰同域源。
- 导入阅读可选择已安装的阅读分支。
- 解析下载改为直连、同域串行和短间隔重试，减少漏读和误失败。
- 检验耗时独立显示。
