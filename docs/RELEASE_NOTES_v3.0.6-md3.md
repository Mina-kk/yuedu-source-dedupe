# 3.0.6-md3 发布说明

基线：3.0.5-md3（versionCode 307，含类型分组戳、登录源清理、弹窗验证码删除）。

## 校验对话框界面

- 功能开关统一为与主页一致的 Material 3 Switch，并收进一张独立功能卡。
- 卡内自上而下依次为：「清理需要登录的源 / 删除弹窗验证码的源 / 快速模式 / 快速准确（推荐）」，每项上下留白一致。
- 「快速准确」说明行只跟随该项，位于同一卡片层级内。
- 校验步骤（搜索/发现/详情/目录/正文）与类型多选（小说/漫画/视频/音频/文件）仍为复选框，未换控件。

## 快速准确预设

- 一键预设：默认只测搜索 + 详情、探测 3 轮、超时 60 秒。
- 勾选即套用预设并锁定滑杆，取消即退出预设并恢复手动步骤选择。
- 关闭同域速度淘汰：同域源只按速度排序参考，绝不淘汰。
- 默认保留未通过 / 待复核源（`仅导出可用源` 在快速准确下自动关闭，不误删）。

## 同域最快收紧

- 速度只是排序参考，本身不构成删除依据。
- 真正淘汰需同时满足：手动模式开启 + 与最快源为完整身份等价副本（URL + 名称 + 完整 raw 深等）+ 耗时差超出接近范围且确认稳定更快。
- 规则/路径/字段不同的同域源一律保留，不建重复组，不计入重复删除。

## 校验证据

- 证据按 `SourceRecord` 实例 + 「URL + 名称 + 完整 raw」唯一指纹匹配。
- 绝不按裸 URL 共享：同 URL 规则不同的源互不套用校验结果。
- 启用步骤有规则但链路 URL 缺失的源记为「未覆盖 / 待复核」，不计失败、不参与淘汰。
