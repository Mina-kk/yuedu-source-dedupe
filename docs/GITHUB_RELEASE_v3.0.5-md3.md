# 阅读书源去重 3.0.5-md3

本版本在 3.0.2 校验能力上增加类型分组、登录源清理、弹窗验证码删除，并加快解析下载。

## 主要更新

- 导出保留原分组，追加 `✔年月日分类（数量）`。
- 「清理需要登录的源」（默认开）。
- 检验配置「删除弹窗验证码的源」（默认勾）。
- 检验对话框阶段勾选、校验类型各排一行。
- 检验进度卡固定两行，避免窗口抖动。
- 解析下载：同域最多 2 路并行，请求 gzip，连接超时 5 秒，DNS 失败不重试。
