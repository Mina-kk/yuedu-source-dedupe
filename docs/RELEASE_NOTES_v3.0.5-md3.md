# 3.0.5-md3 发布说明

基线：3.0.2-md3（versionCode 304，含检验进度卡防抖）。

## 导出分组

- 保留原 `bookSourceGroup`。
- 追加 `✔年月日分类（数量）`，例如 `✔2026-8-23小说（120）`。
- 不再写总戳「检验去重（优质N）」。

## 登录与验证码

- 去重页「清理需要登录的源」（默认开）：`loginUrl` 非空或存在实际 `loginUi` 时，不导入、不保存。
- 检验配置「删除弹窗验证码的源」（默认勾）：检出后从结果中删除。
- 这两项都不写入阅读自定义分组。

## 检验界面

- 搜索 / 发现 / 详情 / 目录 / 正文排成一行。
- 小说 / 漫画 / 视频 / 音频 / 文件排成一行。
- 检验进度卡固定两行并节流刷新。

## 解析下载

- 同域最多 2 路并行。
- 请求 gzip。
- 连接超时 5 秒；DNS 失败不重试。
- 下载后不再为进度先完整解析一遍 JSON。
