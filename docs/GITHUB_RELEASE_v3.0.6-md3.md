# 阅读书源去重 3.0.6-md3

本版本统一校验对话框功能开关为 Material 3 Switch 功能卡，新增「快速准确」一键预设，并把同域速度淘汰收紧为仅完整身份等价副本可删。

## 主要更新

- 校验对话框功能开关改为与主页一致的 Material 3 Switch 功能卡，顺序为：「清理需要登录的源 / 删除弹窗验证码的源 / 快速模式 / 快速准确（推荐）」。
- 「快速准确（推荐）」预设：默认只测搜索 + 详情、3 轮、超时 60 秒。
- 快速准确关闭同域淘汰，并默认保留未通过 / 待复核源（不误删）。
- 同域速度仅参考：仅完整身份等价副本且手动模式才允许淘汰。
- 校验证据不按裸 URL 共享，同 URL 不同规则源互不套用结果。
- 步骤与类型多选仍为复选框。
