# 阅读书源去重 3.0.0-md3

本版本完成 Material 3 和标准 Android Gradle 工程重构，并更新了去重、导入、YCK 和书源校验功能。

## 主要更新

- 重构为标准 Android Gradle 工程和 Material 3 界面。
- 修复 URL 尾斜杠、默认端口、查询参数和跟踪参数的去重处理。
- 支持书源 URL 身份标签，标准和严格模式不再误合并同站不同源。
- 支持本地文件和网络地址导入，兼容多种 JSON 根结构。
- 网络地址直接请求，不使用额外代理。
- YCK 新增站点入口切换和无缓存刷新。
- 新增搜索、发现、详情、目录和正文阶段校验。
- 校验并发范围为 **1–100**，默认 8。
- 支持停止校验、失败原因分类和仅导出可用源。
- “导入阅读”改为打开阅读的批量选择界面，不直接写入阅读书源数据库。
