# 3.0.2-md3 发布说明

基线：3.0.1-md3（versionCode 303）。

## 书源校验

- 检验仍按阅读 CheckSource 分组，不以「网页能打开」判定可用。
- 探测轮数默认 10、最高 10；成功过半才可用，耗时取成功轮中位数。
- 校验并发上限由 100 提高到 500，默认仍为 8。
- 网站失效、超时或已过半即停；收尾不再额外请求。
- 校验后按同类型同域名只保留最快可用源（`www` 视为相同）；耗时接近则都保留。
- 小说 / 漫画 / 音频 / 视频 / 文件互不合并。
- 停止校验后保留已完成结果，不按未确认耗时淘汰同域源。
- `#简体`、`#🎃` 等身份标签导出保留，校验请求只使用井号前地址。
- 检验耗时独立刷新。

## 解析下载

- 主页解析并发 1–10。
- 同域一次只下一份；不同站点仍可并发。
- 只走直连，不使用额外代理。
- 使用常见移动浏览器 User-Agent。
- 超时 / 重置 / 429 / 5xx / 空体最多再试 2 次。
- 404 / 403 不重试。
- 支持同行、中文逗号分隔的多个地址，并去掉 BOM / JSONP / HTML 包裹。

## 导入阅读

- 扫描已装且能响应 `legado://import/bookSource` 的阅读分支。
- 未安装会提示；只有一个则直达；多个弹出选择器。
- 继续打开阅读的书源批量选择界面，不直接写入阅读书源数据库。

## 不采用

附件 HTML「书源网址检测工具」不是检验标准，不会剥掉身份标签，也不会把同域淘汰项改标成不可用。
