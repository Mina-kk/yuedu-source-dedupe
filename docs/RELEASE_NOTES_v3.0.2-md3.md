# 阅读书源去重 3.0.2-md3

基线：3.0.1-md3（versionCode 303）。

## 变更

- 检验仍按阅读 CheckSource 分组，不以「网页能打开」判定可用。
- 探测轮数默认 10、最高 10；成功过半才可用，耗时取成功轮中位数。
- 校验并发上限由 100 提高到 500，默认仍为 8。
- 校验后按同类型同域名只保留最快可用源（www 视为相同）；耗时接近则都保留。
- 小说 / 漫画 / 音频 / 视频 / 文件互不合并。
- `#简体`、`#🎃` 等身份标签导出保留，校验请求只使用井号前地址。
- 导入阅读时扫描已装分支：未安装会提示，只有一个则直达，多个弹出选择器。
- 停止校验后保留已完成结果，不按未确认耗时淘汰同域源。
- 主页解析并发 1–10。校验按线程池并发；失效/过半早停；收尾不再重打 HTTP。
- 显示检验耗时，并提示过慢原因。

## 不采用

附件 HTML「书源网址检测工具」不是检验标准，不会剥掉身份标签，也不会把同域淘汰项改标成不可用。
