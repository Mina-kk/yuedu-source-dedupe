# 阅读书源去重 3.0.1-md3

本版本为书源校验增加搜索关键词、类型判断和结果区类型开关。

## 主要更新

- 校验对话框可填写搜索关键词，默认「我的」。
- 超时、并发、关键词和校验勾选会记住，并支持重置默认。
- 按书源类型判断小说、漫画、视频、音频和文件。
- 内容探测按类型进行。
- 结果区显示去重和校验统计。
- 可用开关选择导入或保存的类型。
- 导入阅读仍打开阅读的批量选择界面，不直接写入阅读书源数据库。
